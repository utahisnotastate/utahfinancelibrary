# Глоссарий

> **Языки:** [English](../glossary.md) · [Eesti](../et/glossary.md) · Русский

> Термины оставлены в оригинале (они соответствуют именам в коде и API); определения переведены на русский.

| Термин | Определение |
|--------|-------------|
| **Adelic Clearinghouse Bypass** | Путь расчёта, который верифицирует локально-глобальную платёжеспособность и допускает нулевой моделируемый залог при прохождении проверок |
| **AllocationIntent** | Инструкция переместить капитал между площадками для снижения трения доходности |
| **Atomic settlement** | Исполнение сделки и финальное обновление реестра происходят за один шаг |
| **AutonomousAuditor** | Движок, обнаруживающий межплощадочную утечку капитала |
| **Capital drag** | Потерянная доходность от удержания активов на неоптимальных площадках |
| **Hasse-Minkowski verifier** | Компонент, выполняющий вещественные + модулярные проверки платёжеспособности перед расчётом |
| **Harvest** | Реализованное событие доходности, обрабатываемое движком расчётов |
| **Humanitarian abundance matrix** | Настроенный кошелёк/маршрут для распределения на воздействие (по умолчанию 5,7%) |
| **k-sunflower routing** | Разбиение узлов ликвидности на непересекающиеся лепестки размером ≤ k |
| **Omnibus audit** | Связка булевых проверок: десятина, спектральная жёсткость, непересекающаяся маршрутизация |
| **Orthogonal phase-lock** | Активация $\sin(x)e^{-x^2/2}$ в скрытом слое PINN |
| **PINN** | Физически информированная нейросеть — функция потерь включает структурный физический штраф |
| **Protocol tithe** | Неизменное распределение 2,3% суверенному протоколу |
| **SettlementInstruction** | Одна строка выплаты (кошелёк, сумма, метка маршрута) |
| **Sovereign vault** | Слой кастоди намерений с пороговой подписью |
| **Sunflower petal** | Один непересекающийся набор узлов капитала в топологии маршрутизации |
| **UCE** | Utah Container Engine — внешний рантайм развёртывания, упоминаемый в Utahfile |
| **Utahfile** | YAML-манифест, описывающий сервисы, хуки и конфигурацию движка |
| **Verification lattice** | `InvarianceValidationLattice` — математические проверки во время выполнения |
| **Wave telemetry** | Статистика в ограниченном кольцевом буфере по рыночным тикам |
| **Zero collateral** | `required_collateral == 0` после адельной верификации |
| **Persistent homology** | Многомасштабное топологическое резюме формы данных (числа Бетти, штрихкоды) |
| **Betti numbers** | $b_0$ компоненты, $b_1$ петли, $b_2$ пустоты комплекса |
| **Topological Risk Parity (TRP)** | Распределение, обратно взвешенное по топологической нагрузке заражения |
| **Vietoris-Rips complex** | Симплициальный комплекс, построенный соединением точек в пределах радиуса |
| **Wasserstein barcode distance** | Расстояние оптимального транспорта между диаграммами персистентности |
| **Ricci flow** | PDE $\partial_t g_{ij} = -2R_{ij}$, эволюционирующее метрику к постоянной кривизне |
| **Ricci flow covariance** | Ковариация, шумоподавленная эволюцией её как риманова метрика |
| **Navier-Stokes routing** | Ребалансировка, моделируемая как несжимаемый (сохраняющий массу) поток жидкости |
| **Velocity field** | Непрерывные скорости потока капитала, возвращаемые решателем маршрутизации |
| **Spectral CVaR veto** | Триггер остановки, когда спектральный радиус оператора потерь пробивает стену |
| **Symplectic Veto** | Действие остановки исполнения, запускаемое супервизором спектрального CVaR |
| **Dirichlet boundary conditions** | Фиксация собственных функций к заданным значениям на краю области |
| **Christoffel symbols** | $\Gamma^k_{ij}$, коэффициенты связности метрики |
| **Riemann tensor** | $R^l{}_{ijk}$, полная кривизна риманова многообразия |
| **Ricci tensor** | $R_{jk}$, след Римана; управляет потоком Риччи |
| **Scalar curvature** | $R = g^{jk}R_{jk}$, однозначная кривизна |
| **Laplace-Beltrami operator** | $\Delta_M$, лапласиан на римановом многообразии |
| **Principal eigenvalue** | Наименьшее собственное значение Дирихле $\lambda_0$ генератора |
| **Feynman-Kac bound** | $\mathbb{P}(\sup\text{DD}>\mathcal D_{max})\le Ce^{-\lambda_0 T}$ |
| **Volume-normalised Ricci flow** | Поток Риччи с членом, фиксирующим объём, сходящийся к постоянной кривизне |
| **Betti-Number Divergence Test** | Диагностика краха: сырое $b_0\to1$ против детонированного $b_0>1$ |
| **Detoning** | Удаление доминирующих рыночных/системных собственных мод из матрицы корреляций |
| **Quadratic covariation** | $\langle X_i,X_j\rangle_t$, независимый от сноса путевой предел суммы квадратов приращений |
| **Pathwise metric tensor** | $g_{ij}(t)=\tfrac{d}{dt}\langle X_i,X_j\rangle_t$, измеренная (не оценённая) метрика |
| **Realized covariation** | Сумма внешних произведений приращений лог-доходностей; сходится к $\langle X\rangle_t$ при $dt\to0$ |
| **TSRV** | Two-Scale Realized Covariance: шумоустойчивая оценка ковариации для сырых тиков |
| **Tick observer** | Онлайн-наблюдатель $g_{ij}(t)$ без запаздывания из потока тиков (`tick_observer.py`) |
| **Holographic LOB embedding** | Гиперболическое взвешивание глубины стакана в стиле AdS/CFT в ограниченный признак давления |
| **Von Neumann entropy** | $S(\rho)=-\operatorname{tr}(\rho\log\rho)$; здесь мера диверсификации/концентрации нормированной ковариации |
| **Effective number of bets** | $e^{S(\rho)}$, число независимых активных направлений риска |
| **Matrix Product State (MPS)** | Тензорно-сетевая факторизация вектора состояния; энтропии связей = запутанность по разрезам |
| **Malliavin derivative** | Чувствительность $D_t F$ функционала пути к возмущению шума; используется для греков |
| **Skorokhod integral** | Антиципирующий (неадаптированный) стохастический интеграл; сопряжённый производной Маллявэна |
| **Protocol yield split** | Прозрачная, настраиваемая маршрутизация чистой/гуманитарной/десятины положительной доходности (`protocol_economics.py`) |
