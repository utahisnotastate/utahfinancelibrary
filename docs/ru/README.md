## Исследовательские / SOTA физические модули

Помимо руководств выше, библиотека содержит модули исследовательского уровня,
заимствующие аппарат математической физики. Каждый — **настоящий, протестированный
оценщик/диагностика** с честными оговорками (без «бесплатного обеда», оракула или
обещаний нулевого проскальзывания): `holographic_projection.py` (AdS/CFT давление
стакана), `tensor_network_hedge.py` (MPS / энтропия фон Неймана), `chrono_drift.py`
(Маллявэн/Скороход), `jarzynski_harvester.py` (свободная энергия Жарзинского),
`braid_router.py` (Кауффман/Джонс + порядок исполнения), `koopman_oracle.py`
(прогноз Купмана/EDMD). Вся положительная доходность маршрутизируется через
прозрачный `enforce_universal_tithe`.

## Оплата Utah

Десятина протокола 2,3% и гуманитарное распределение — это внутренние учётные
маршруты библиотеки. Чтобы **совершить реальный платёж Utah** — спонсорство,
перечисление десятины или поддержка — свяжитесь напрямую:

> **Контакт:** [utah@utahcreates.com](mailto:utah@utahcreates.com)

Пока это ручной шаг (письмо для согласования метода, реквизита и суммы).
**Планируется отдельное GUI-приложение**, которое будет управлять платежами Utah
от начала до конца — генерировать реквизиты перевода, отслеживать
десятину/гуманитарное распределение и фиксировать поступления — так что это станет
делом нескольких кликов. До его выхода указанная почта — канонический способ
оплаты Utah.

## Быстрые команды

```bash
# Полный конвейер (аудит → маршрутизация → расчёты → адельный → альфа)
python -m src.app.utah_prime_sieve_daemon

# Демо адельного нулевого залога
python -m src.app.hasse_minkowski_daemon

# JAX-движок альфы (требует pip install -e ".[jax]")
python -m src.models.pinn_jax_runtime

# Проверить хуки Utahfile v6
python -m src.app.ignite --manifest Utahfile --dry-run
```

## Важная оговорка

Utah Finance Library предоставляет **программные компоненты с открытым исходным
кодом** для аудита портфеля, маршрутизации, генерации инструкций расчёта и
математической верификации. Она **не**:

- заменяет лицензированные клиринговые палаты или регуляторную отчётность;
- гарантирует доходность инвестиций или устранение риска;
- является юридической, налоговой или инвестиционной консультацией.

Использование в продакшене требует вашего собственного комплаенс-контроля,
юридической проверки и интеграции с одобренной финансовой инфраструктурой.
