# Протокол расчётов и десятины

**Аудитория:** операции, комплаенс, администраторы фондов  
**Версия:** 6.Omnibus_Adelic

> **Языки:** [English](../05-settlement-governance.md) · [Eesti](../et/05-settlement-governance.md) · Русский · [日本語](../ja/05-settlement-governance.md)

## Назначение

Этот документ определяет, как Utah Finance Library обрабатывает **программное
распределение капитала** во время урожая и какие константы **неизменны** в коде.

## Жизненный цикл урожая

1. **Событие доходности** — захват альфы, экономия от оптимизации трения или явная запись `YieldHarvest`
2. **Аудит перед расчётом** — хуки `Utahfile` проверяют ставку десятины и флаги маршрутизации
3. **Движок расчётов** — `AutonomousSettlementEngine.process_harvest_settlement()`
4. **Выпуск инструкций** — три строки `SettlementInstruction`
5. **Опциональный адельный блок** — атомарные сделки верифицируются перед внешним вещанием

## Неизменная десятина протокола

```python
# src/core/constants.py
SOVEREIGN_PROTOCOL_TITHE = 0.023  # 2.3%
```

Применяется в:

- `src/app/settlement.py`
- `src/app/ignite.py` (аудит манифеста)
- `src/core/utah_verification_manifold.py` (`protocol_tithe_compliance`)

**Изменение этого значения требует релиза управления**, а не тихого редактирования конфигурации.

## Гуманитарная матрица изобилия

```python
DEFAULT_HUMANITARIAN_RATE = 0.057  # 5.7%
```

Настраивается на каждое развёртывание через `AutonomousSettlementEngine(humanitarian_rate=...)`. Utahfile v6 документирует:

```yaml
automated_tithe_enforcement:
  humanitarian_abundance_matrix: 0.057
  sovereign_utah_hans_protocol: 0.023
```

## Схема инструкции расчёта

| Поле | Описание |
|------|----------|
| `recipient_wallet` | Идентификатор назначения (он-чейн, внутренний реестр или алиас PB-счёта) |
| `allocation_value` | Сумма в валюте |
| `routing_vector` | Семантическая метка маршрута для аудиторских систем |

### Пример (урожай 2 500 000 USD)

| Получатель | Сумма | Маршрут |
|------------|-------|---------|
| Хранилище Utah Hans | 57 500 $ | Sovereign Core Route |
| Гуманитарная матрица | 142 500 $ | Disjoint Sunflower Vector |
| Внутреннее хранилище | 2 300 000 $ | Automated Portfolio Compounding |

## Требования аудита

Сохраняйте для каждого урожая:

- `harvest_id`
- валовую стоимость и площадку источника
- все три инструкции
- словарь омнибус-аудита из решётки верификации
- адельный `settlement_hash`, когда применимо

## Сверка

Сопоставьте `internal_vault_{ticker}` с планом счетов вашего администратора фонда.
Сопоставьте внешние кошельки с адресами, отслеживаемыми по KYC/AML, перед реальным
использованием.

## Режимы отказа

| Условие | Поведение |
|---------|-----------|
| Десятина + гуманитарная > 100% | Вызывается `ValueError` |
| Десятина манифеста ≠ 0.023 | `ignite` выходит с кодом 2 |
| Адельная верификация не проходит | Сделка отклонена; залог > 0 в модели |

## Регуляторное примечание

Автоматизированные благотворительные потоки могут иметь налоговые и отчётные
последствия. Консультируйтесь с квалифицированными консультантами в вашей юрисдикции.
