**Аудитория:** квантовые аналитики, портфельные управляющие, трейдеры исполнения, риск-офицеры  
**Версия:** 6.Omnibus_Adelic

> **Языки:** [English](../02-finance-professionals.md) · [Eesti](../et/02-finance-professionals.md) · Русский · [日本語](../ja/02-finance-professionals.md)

## Краткое резюме для руководства

Если ваш фонд по-прежнему платит семизначные годовые лицензии за Bloomberg AIM,
Enfusion или Aladdin **и** блокирует сотни миллионов в клиринговом залоге, вы
теряете альфу на двух фронтах: **вымогательство за ПО** и **трение залога**.

Utah Finance Library — это альтернатива с открытым исходным кодом, которая
автоматизирует:

1. **Обнаружение трения капитала** — находит потерянную доходность между прайм-брокерами и площадками
2. **Глобальный неттинг** — маршрутизирует ликвидность непересекающимися партиями для снижения перекрытия
3. **Программные расчёты** — распределяет каждый урожай в момент исполнения
4. **Адельный обход** — верифицирует сделки для атомарного расчёта без моделируемого залога CCP (если доказательства платёжеспособности проходят)
5. **Физически информированную альфу** — слой JAX PINN вместо непрозрачного ML «чёрного ящика»
6. **Геометрию непрерывного времени** — измеряет метрический тензор рынка из тиков и спектрально ограничивает просадку вместо устаревших окон оценки ковариации

## Проблема 1: межплощадочная утечка капитала

**Легаси-процесс:** таблицы + выписки прайм-брокера на конец дня. Трение обнаруживается спустя дни.

**Процесс Utah:** `AutonomousAuditor` группирует позиции по тикеру, сравнивает доходность с поправкой на риск и выдаёт `AllocationIntent`, когда трение превышает порог.

Пример лога:

```text
[AUDIT ALERT] Capital leakage in USD at prime_custody_01. Drag: 90000.0000
```

**Действие:** автоматически перенаправьте простаивающий USD с низкодоходной площадки на оптимальную.

## Проблема 2: залог, заблокированный в клиринговой палате

**Легаси-процесс:** сделка исполняется на бирже → клиринговый член вносит залог в DTCC → расчёт T+1 → капитал простаивает всю ночь.

**Процесс Utah:** `HasseMinkowskiVerifier` проверяет:

- **Вещественное поле:** у покупателя есть котируемая валюта, у продавца — базовый актив
- **Локальные поля:** сравнения платёжеспособности по модулю малых простых чисел ($p$-адический суррогат совместимости)
- Если все проходят → `required_collateral = 0` → атомарный обмен в реестре

Демо-сделка высвобождает **2,5 млн $ × 1000 WETH номинала** моделируемого легаси-залога, если верификация проходит.

> **Раскрытие риска:** реальный клиринг включает законные права неттинга, правила CCP и регуляторный капитал. Эта библиотека реализует **модель верификации и реестра**, которую вы должны сопоставить с одобренной инфраструктурой перед продакшеном.

## Проблема 3: деградация стохастической ML-альфы

**Легаси-процесс:** Transformer/LSTM на исторических барах → переобучается на шуме → ломается при смене режима.

**Процесс Utah:** `OrthogonalWaveStatePredictor` навязывает:

- ограниченное многообразие активации (sin × гауссова огибающая)
- штраф якобиана, вдохновлённый Навье-Стоксом, во время обучения
- компиляцию XLA через `compile_bare_metal_graph()`

## Проблема 4: ручная сверка

**Легаси-процесс:** операционная команда сверяет EMS, PB и администратора фонда в конце месяца.

**Процесс Utah:** каждый расчёт порождает детерминированные строки `SettlementInstruction` и хеши расчёта SHA-256 на адельных сделках.

## Проблема 5: статическая ковариация, оценённая на устаревших окнах

**Легаси-процесс:** окно ретроспективы оценивает матрицу ковариации, которую затем
сжимают (Ledoit-Wolf/OAS) и подают в решатель выпуклой оптимизации. Оценка
отстаёт от рынка и включает выбор длины окна и ошибку оценки.

**Процесс Utah:** [Топологическое распределение в непрерывном времени](08-continuous-time-allocation.md)
**измеряет** геометрию рынка, а не моделирует её:

- `QuadraticCovariationObserver` считывает путевой метрический тензор
  `g_ij(t) = d/dt ⟨X_i, X_j⟩_t` прямо из потока тиков — **без окна ретроспективы,
  без запаздывания** — с двухмасштабной оценкой (TSRV) для шума микроструктуры.
- `compute_ricci_flow_covariance` шумоподавляет эту метрику **точным autodiff**
  нормированным потоком Риччи (`jax.jacfwd`, без прокси на конечных разностях).
- `feynman_kac_drawdown_bound` превращает главное собственное значение
  Лапласа-Бельтрами в аналитическую верхнюю границу просадки
  `P(sup DD > D_max) ≤ C e^{-λ₀T}`.
- `betti_number_divergence_test` помечает топологию заражения: при синтетическом
  крахе сырое многообразие корреляций схлопывается (`b₀ → 1`), тогда как
  детонированное многообразие топологического риск-паритета сохраняет разделение
  кластеров.

## Миграция с `riskfolio-lib`

Набор непрерывного времени предоставляет геометрические аналоги обычным процессам
`riskfolio-lib`:

| riskfolio-lib | Аналог Utah |
|---------------|-------------|
| `HCPortfolio` (HRP/NCO) | `optimize_topological_risk_parity` |
| Сжатие Ledoit-Wolf / OAS | `compute_ricci_flow_covariance` (точный autodiff) |
| Выборочная/EWMA ковариация | `QuadraticCovariationObserver` (путевая, нулевое запаздывание) |
| Ограничение оборота L1 | `calculate_navier_stokes_rebalance_flow` |
| Mean-CVaR / EVaR / Max-DD | `apply_spectral_cvar_veto`, `feynman_kac_drawdown_bound` |

Геометрия точна (проверена на 2-сфере с точностью `1e-5`), и путевая метрика —
это $\mathcal{F}_t$-измеримая наблюдаемая величина, а не оценённый параметр. Когда
реальные биржевые тики содержат шум микроструктуры, двухмасштабная оценка убирает
ведущее смещение. Как и с любым новым методом, проверьте на существующих выпуклых
эталонах перед перераспределением капитала.

## Путь миграции с Bloomberg / Enfusion

1. **Неделя 1:** экспортируйте позиции по площадкам → подайте в список `AssetPosition`
2. **Неделя 2:** теневой режим намерений (без исполнения)
3. **Неделя 3:** подключите снимки хранилища для адельной верификации
4. **Неделя 4:** пилот атомарного расчёта во внутреннем реестре
5. **Постоянно:** постепенная интеграция потоков EMS/PB
