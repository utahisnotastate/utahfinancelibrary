# 絶対的な金融主権

**対象読者:** 非技術系の責任者、ファミリーオフィスの代表、ファンド創業者  
**バージョン:** 6.Omnibus_Adelic

> **言語:** [English](../03-founders-family-offices.md) · [Eesti](../et/03-founders-family-offices.md) · [Русский](../ru/03-founders-family-offices.md) · 日本語

## Utah Finance Library とは？

これは **箱入りのオープンソース・ヘッジファンド** のようなものだと考えてください。
銀行やブローカーにあるあなたのお金を一緒に監視し、無駄を見つけ、資本を効率的に
動かし、安全になり次第すぐに取引を決済し、利益を自動で分配する（慈善を含む）一連
のプログラムです。

あなたが主導権を握り続けます。どのベンダーもスタック全体を所有しません。

## どんな問題を解決するの？

### 1. お金が間違った場所にある

多くの一族は、複数の銀行やブローカーに現金を保有しています。ある口座はほとんど
利息を生まず、別の口座はもっと生みます。本ライブラリはあなたのお金がどこで最も
稼げていないかを **継続的に確認** し、より良い会場への移動を推奨（または実行）します。

### 2. 見えない手数料

従来のプラットフォームは隠れたコストを積み上げます。データ料、執行マークアップ、
管理手数料です。本ライブラリは **すべての分配をコードで可視化** します — 特に、
すべての利益イベントでプログラムされた配分を。

### 3. 弁護士・会計士を定型業務に

法人設立や月末会計は複雑な案件では今も専門家を要しますが、**定型的なルーティング、
ネッティング、決済指示** はセットアップ後に自動で動かせます。

### 4. 隠蔽によるセキュリティ 対 証明

銀行のマーケティングを信用する代わりに、金庫レイヤーは **複数署名の意図** を使い
ます。重要な移動には複数の承認が必要で、暗号学的ハッシュで記録されます。

## 組み込みのガバナンス: 什一と人道配分

システムが「収穫」（利益イベント）を処理すると、お金を自動で分割します。

| 取り分 | 既定 | 行き先 |
|--------|------|--------|
| 議定書什一 | **2.3%** | Utah Hans 主権議定書（ライブラリ維持） |
| 人道 | **5.7%** | 人道支援の豊穣マトリクス（インパクト） |
| 再投資 | 残り | あなたの内部金庫 |

人道の割合は設定で引き上げられます。**2.3% の什一はコードで固定** されています。

## アデール的優位（やさしい言葉で）

今日、大口取引はしばしば、決済が完了するまで中央清算機関に **担保を差し入れる**
ことを要求します。そのお金はほとんど稼がず、他に投資もできません。

本ライブラリの **アデール的清算機関バイパス** は、取引の両当事者を数学的に検証
します。**モデルが確認する範囲で** 両者が支払うべきものを証明可能に保有していれば、
取引はソフトウェア台帳上で **追加担保ゼロで即時に決済** できます。

数億ドルを死んだ担保から解放するファンドは、その資本を同じ日に利回り戦略へ投じ
られます。

> 実際の取引相手と使う前に、弁護士とプライムブローカーを関与させてください。規制は依然として適用されます。

## リスクを推測ではなく測定する

ほとんどのリスクシステムは、先月のデータを使って資産がどう一緒に動くかを **推定**
し、その後何が起こりうるかを推測します。その推定は常に少し古びています。

本ライブラリは異なるアプローチを取ります。温度計が温度を予測ではなく読み取るよう
に、市場の生きた「形」を価格ティックから直接 **測定** します。その測定された形か
ら、選んだ期間で **ドローダウンがどれほど悪化しうるかの数学的な上限** を計算し、
市場構造が一つの伝染の塊へ崩れ始めたときに警告できます（クラッシュ伝播前の前兆）。

簡単に言えば、古びた推測が減り、「どれほど悪くなりうるか」という明確な数値が得られ、
システミックストレスの早期警告灯がともります。これは高度な数学ですが、出力はチーム
が行動できるシンプルなガードレールです。（いつものように、実際の資本でどの数値を
信頼する前にも、既存のリスクプロセスに対して検証してください。）

## 実行に必要なもの

- 一般的なクラウドサーバー（AWS、DigitalOcean、自社ラック）
- インストール済みの Python
- 任意: 高度なアルファモデル用の JAX

専有的なハードウェアは **不要** です。

## はじめるための 2 コマンド（デモ）

```bash
pip install -e .
python -m src.app.utah_prime_sieve_daemon
```

デプロイマニフェストの検証:

```bash
python -m src.app.ignite --manifest Utahfile --dry-run
```

## 誰が最初に移行すべき？

- **遊休現金の摩擦** を抱える複数会場の一族
- **高いプライムブローカレッジと管理の重複** を支払うファンド
- **オープンソース運用** に慣れているチーム
- すべての利益で **プログラム可能な慈善** を望む責任者
