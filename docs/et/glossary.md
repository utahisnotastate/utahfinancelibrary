# Sõnastik

> **Keeled:** [English](../glossary.md) · Eesti · [Русский](../ru/glossary.md)

> Mõisted on jäetud algkujule (need vastavad koodi ja API nimedele); määratlused on tõlgitud eesti keelde.

| Mõiste | Määratlus |
|--------|-----------|
| **Adelic Clearinghouse Bypass** | Settlement-tee, mis verifitseerib lokaal-globaalse maksevõime ja lubab kontrollide läbimisel nullmodelleeritud tagatist |
| **AllocationIntent** | Juhis liigutada kapitali platvormide vahel tulususe hõõrdumise vähendamiseks |
| **Atomic settlement** | Tehingu täitmine ja lõplik pearaamatu uuendus toimuvad ühe sammuna |
| **AutonomousAuditor** | Mootor, mis tuvastab platvormideülese kapitalilekke |
| **Capital drag** | Kaotatud tulusus varade hoidmisest mitteoptimaalsetel platvormidel |
| **Hasse-Minkowski verifier** | Komponent, mis teostab reaal- + mooduli maksevõime kontrollid enne settlement’i |
| **Harvest** | Realiseeritud tulusündmus, mida töötleb settlement-mootor |
| **Humanitarian abundance matrix** | Seadistatud rahakott/marsruut mõjuallokatsiooniks (vaikimisi 5,7%) |
| **k-sunflower routing** | Likviidsussõlmede partitsioneerimine lahusolevatesse kroonlehtedesse suurusega ≤ k |
| **Omnibus audit** | Bullean-kontrollide kimp: kümnis, spektraalne jäikus, lahusolev marsruutimine |
| **Orthogonal phase-lock** | Aktiveerimine $\sin(x)e^{-x^2/2}$ PINN-i peidetud kihis |
| **PINN** | Füüsikateadlik närvivõrk — kadu sisaldab struktuurilist füüsikatrahvi |
| **Protocol tithe** | Muutumatu 2,3% allokatsioon suveräänsele protokollile |
| **SettlementInstruction** | Üksik väljamakserida (rahakott, summa, marsruudisilt) |
| **Sovereign vault** | Lävega allkirjastatud kavatsuste hoidlakiht |
| **Sunflower petal** | Üks lahusolev kapitalisõlmede komplekt marsruutimistopoloogias |
| **UCE** | Utah Container Engine — Utahfile’is viidatud väline juurutuskäituskeskkond |
| **Utahfile** | YAML-manifest, mis kirjeldab teenuseid, konkse ja mootori seadistust |
| **Verification lattice** | `InvarianceValidationLattice` — matemaatilised käitusaja kontrollid |
| **Wave telemetry** | Piiritletud ringpuhvri statistika turutiksudel |
| **Zero collateral** | `required_collateral == 0` pärast adeelset verifitseerimist |
| **Persistent homology** | Andmete kuju mitmeskaalaline topoloogiline kokkuvõte (Betti arvud, vöötkoodid) |
| **Betti numbers** | $b_0$ komponendid, $b_1$ lingid, $b_2$ õõnsused kompleksis |
| **Topological Risk Parity (TRP)** | Allokatsioon, mis on pöördvõrdeliselt kaalutud topoloogilise nakkuskoormusega |
| **Vietoris-Rips complex** | Simplitsiaalkompleks, mis ehitatakse raadiuse sees olevaid punkte ühendades |
| **Wasserstein barcode distance** | Optimaalse transpordi kaugus püsivusdiagrammide vahel |
| **Ricci flow** | PDE $\partial_t g_{ij} = -2R_{ij}$, mis arendab meetrikat konstantse kõveruse poole |
| **Ricci flow covariance** | Kovariatsioon, mis on mürafiltreeritud, arendades seda Riemanni meetrikana |
| **Navier-Stokes routing** | Tasakaalustamine, modelleeritud kokkusurumatu (massisäilitava) vedeliku vooluna |
| **Velocity field** | Pidevad kapitalivoo määrad, mida tagastab marsruutimislahendaja |
| **Spectral CVaR veto** | Peatamise käivitaja, kui kadu-operaatori spektraalraadius murrab seina |
| **Symplectic Veto** | Täitmise peatamise tegevus, mille käivitab spektraalne CVaR järelevaataja |
| **Dirichlet boundary conditions** | Omafunktsioonide kinnitamine fikseeritud väärtustele valdkonna äärel |
| **Christoffel symbols** | $\Gamma^k_{ij}$, meetrika sidususkoefitsiendid |
| **Riemann tensor** | $R^l{}_{ijk}$, Riemanni muutkonna täielik kõverus |
| **Ricci tensor** | $R_{jk}$, Riemanni jälg; juhib Ricci voogu |
| **Scalar curvature** | $R = g^{jk}R_{jk}$, ühe arvu kõverus |
| **Laplace-Beltrami operator** | $\Delta_M$, Laplacian Riemanni muutkonnal |
| **Principal eigenvalue** | Generaatori väikseim Dirichlet’ omaväärtus $\lambda_0$ |
| **Feynman-Kac bound** | $\mathbb{P}(\sup\text{DD}>\mathcal D_{max})\le Ce^{-\lambda_0 T}$ |
| **Volume-normalised Ricci flow** | Ricci voog liikmega, mis hoiab mahtu fikseerituna, koondudes konstantse kõveruse poole |
| **Betti-Number Divergence Test** | Krahhi diagnostika: toore $b_0\to1$ vs detoneeritud $b_0>1$ |
| **Detoning** | Domineerivate turu/süsteemsete omamoodide eemaldamine korrelatsioonimaatriksist |
| **Quadratic covariation** | $\langle X_i,X_j\rangle_t$, triivisõltumatu rajapõhine summeeritud ruutsuurenemiste piir |
| **Pathwise metric tensor** | $g_{ij}(t)=\tfrac{d}{dt}\langle X_i,X_j\rangle_t$, mõõdetud (mitte hinnatud) meetrika |
| **Realized covariation** | Logaritmtulususe suurenemiste väliskorrutiste summa; koondub $\langle X\rangle_t$-le kui $dt\to0$ |
| **TSRV** | Two-Scale Realized Covariance: mürakindel kovariatsiooni hinnang toore tiksu jaoks |
| **Tick observer** | Online mahajäämuseta $g_{ij}(t)$ vaatleja tiksuvoost (`tick_observer.py`) |
| **Holographic LOB embedding** | AdS/CFT-stiilis hüperboolne tellimusraamatu sügavuse kaalumine piiritletud rõhutunnuseks |
| **Von Neumann entropy** | $S(\rho)=-\operatorname{tr}(\rho\log\rho)$; siin normaliseeritud kovariatsiooni mitmekesistamise/kontsentratsiooni mõõt |
| **Effective number of bets** | $e^{S(\rho)}$, sõltumatute aktiivsete riskisuundade arv |
| **Matrix Product State (MPS)** | Olekuvektori tensorvõrgu faktoriseering; sideme entroopiad = põimitus üle lõigete |
| **Malliavin derivative** | Raja-funktsionaali $D_t F$ tundlikkus müra häiritusele; kasutatakse Greekide jaoks |
| **Skorokhod integral** | Anticipeeriv (mitteadapteeritud) stohhastiline integraal; Malliavini tuletise kaasoperaator |
| **Protocol yield split** | Läbipaistev, seadistatav neto/humanitaar/kümnise marsruutimine positiivsest tulust (`protocol_economics.py`) |
